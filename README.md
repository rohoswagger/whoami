# whoami

My personal site — a small home for my work, writing, docs, and the things that shape how I think.

I'm Roshan Desai. I build things, currently including product and growth work at Onyx. This site was designed and built with SwagUI, then implemented with Next.js, React, Tailwind CSS, and Bun.

## Run it locally

```bash
bun install
bun dev
```

Visit [http://localhost:4000](http://localhost:4000).
